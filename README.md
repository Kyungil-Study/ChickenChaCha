## 📖 Project Overview [프로젝트 개요]

- 오프라인 보드 게임 **치킨차차** 를 온라인 PC 게임으로 이식한 모작 프로젝트입니다.  
- **Unity 3D** 로 제작한 게임입니다.  
- **개발 기간:** 2025.5 ~ 2025.5 (2주)  

---

## ✨ Key Features [주요 기능]

### 🧩 Manager
- **GameManager:** 마스터 클라이언트를 통해 게임 흐름 관리  
- 플레이어 기반 **자동 공격**  
- 몬스터 위치를 계산하여 **무기 발사 방향 자동 설정**  

### 🎮 Player
- 주변 보드의 다른 유저의 위치에 따라 연출 애니메이션이 동적으로 변경  

### 🗺️ Board
- 각 보드 타일 별로, 유저 존재 여부 상태 관리  
- **RayCast 기반**으로 타일 이동 지원  

### 👥 Friend & Game Invite
- **Firebase 컬렉션** 기반으로 유저별 친구목록 관리  
- 게임에 친구 초대 지원  

---

## 🛠 Tech Stack [기술 스택]

- **C#**  
- **Unity 2022.3.16**  
- **Fusion2** (인게임 네트워크)  
- **Firebase** (유저 관리, 친구, 초대)  
- **Notion** (프로젝트 업무 관리)  
- **GitHub** (형상 관리)
